02

领用三步

不用会写代码也能先把额度拿到手；要接 API 时再看第三步。

STEP 01

挑一个入口

先看免费类型：想长期用挑“长期免费 / 免费层”，想短期冲量挑“限时活动”，别在快截止的活动上做长期项目。

STEP 02

用官方账号注册

手机号或邮箱注册、按提示实名。赠送额度通常在注册后自动到账，部分平台要去活动页手动领取。

STEP 03

建 Key 直接调用

在控制台创建 API Key，把 base_url 换成平台地址即可。多数平台兼容 OpenAI 格式，客户端里填上就能跑。

提示

额度是“现在”的，不是“永久”的。平台常改规则，用之前点进控制台确认一眼；本站只做入口与摘要，不代领、不代跑。

05

常见问题

关于收录标准、更新节奏与怎么用，几个直接的答案。

Q1要注册、要付费吗？

都不用。整站是纯静态页面，打开就能看，不收集个人信息、没有登录。左右侧栏是广告位，单独标注、与收录结果无关；所有领取动作都在各平台官方页面完成。

Q2收录标准是什么？

只收“现在还能领、并且能直接调用模型”的入口：长期免费、注册赠送、每日赠送、免费层、限时活动五类。额度太小、只送一次性体验金、或必须绑卡才发额度的，一般放进观望区。

Q3额度会一直有效吗？

不会。免费额度天生有时效，平台可能随时收紧或取消。卡片上的截止日只针对“活动领取窗口”，不代表额度永久有效，用前请在控制台确认。

Q4领不到 / 链接失效怎么办？

先确认是不是地区限制或需要实名。若入口确实失效，改 assets/data.js 里对应条目即可——整站数据都在这一个文件里，删一行就等于下架。

Q5能帮我接入 API、写代码吗？

这里只做导航与摘要，不代接、不代跑。第三步给了通用接法：换成平台的 base_url 和 Key，多数客户端都能直接用。
