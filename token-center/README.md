# Token Center（Token 中心）

免费 AI 额度导航站。纯静态页面，双击 `index.html` 就能打开，不需要服务器、不需要登录、没有后端。

## 目录结构

```
token/
├─ index.html          首页（唯一页面，含左右广告位）
├─ assets/
│  ├─ style.css        全部样式（配色变量、广告位、动效、响应式）
│  ├─ data.js          全部内容数据（全部 token / 观望区 / 已下架）
│  └─ app.js           渲染、筛选、搜索、截止日倒计时、动效调度
└─ README.md
```

## 怎么打开

- 本地看：直接双击 `index.html`。
- 想放线上：把整个 `token` 文件夹丢到任意静态托管（对象存储、Vercel、Cloudflare Pages、Nginx）即可，无构建步骤。

## 怎么改内容

所有内容都在 `assets/data.js`，改完保存、刷新页面就生效。

新增一条 token，往 `DATA.items` 里加一个对象：

```js
{
  n: '某某平台',              // 名称
  cat: 'model',              // model 模型额度 / tool AI 工具 / event 限时活动
  free: '长期免费',           // 长期免费 / 限时活动 / 注册赠送 / 每日赠送 / 免费层 / 试用
  models: 'DeepSeek · Qwen',  // 覆盖模型，用 · 分隔
  quota: '每天 100 万 tokens，注册即到账。',  // 额度摘要，写人话
  url: 'https://example.com', // 官方入口
  dl: '2026-12-31',           // 截止日，没有就删掉这一行
  hot: true,                  // 站长推荐（会排到最前）
  intl: true                  // 海外平台（模型行前会标“海外”）
}
```

- `watch`（观望区）、`retired`（已下架）的字段是 `n` / `url` / `why`，`why` 写一句为什么放这儿。
- 改完 `updated` 字段，页面顶部和页脚的“最近核验”会自动跟着变。
- 所有数字（收录数、限时活动数、各分类数量）都是脚本按数据实时算的，不用手改。

## 设计规范（保持一致的几个点）

| 项目 | 取值 |
| --- | --- |
| 底色 | `#F7F4EC` 暖纸白 |
| 卡片 | `#FFFFFF` + 1px 发丝线 `rgba(28,37,40,.10)` + 圆角 14px |
| 主色 | `#2E6D7E` 墨青（文字标签用 `#235765`） |
| 辅助色 | 长期免费绿 `#3E8A67`、限时活动琥珀 `#B07C24`、推荐珊瑚 `#C05743` |
| 字体 | 系统中文黑体；数字/英文用等宽字体做“数据感” |
| 节奏 | 区块间距 54px，卡片间距 14px，正文 13px / 行高 1.62 |

改配色只改 `style.css` 顶部 `:root` 里的变量，全站会自动统一。

## 广告位

左右各一块，写在 `index.html` 底部的 `<aside class="rail rail-l / rail-r">` 里：

- **只在 ≥1580px 的宽屏出现**，两栏广告各占 170px，正文仍是 1140px 居中，互不挤压；1580px 以下自动隐藏，移动端完全不出现。
- 广告块高度自适应：`min(600px, 100vh - 150px)`，矮屏不会超出视口。
- 当前是虚线占位（`AD / 广告位招租 / 170 × 600`）。放入真广告时，把 `.rail-card` 里的文字换成 `<a>` 或 `<img>`，并在图片上标“广告”，避免和收录内容混淆。
- 正文侧已同步改口径：首屏、页脚、FAQ Q1 都注明“广告位单独标注、与收录结果无关”，不再声称“无广告”。

## 动效

都在 `style.css` 的“动效”段落，按 `prefers-reduced-motion` 自动降级（系统开了“减少动态效果”就全部静止）：

| 动效 | 位置 | 说明 |
| --- | --- | --- |
| 首屏依次浮入 | `.hero` | 徽章→标题→摘要→搜索→统计，逐级延迟 80ms |
| 数字滚动 | `.stats` | 四个统计数从 0 缓到真实值，900ms 三次方缓出 |
| 卡片错峰入场 | `.card` | 每次筛选/搜索重排都重新入场，最多叠加 12 张的延迟 |
| 区块滚动进入 | `.section` | IntersectionObserver 触发，进入视口后上浮淡入 |
| 顶栏滚动态 | `.nav` | 滚动 10px 后加深阴影与背景 |
| 悬停位移 | 卡片 / 步骤卡 | 上浮 2px，边框转浅青 |
| 紧急截止脉冲 | `.deadline.urgent` | 当天截止的标签缓慢明暗呼吸 |

改强度就调这几个 `animation` 的时长与延迟；删掉 `@media(prefers-reduced-motion:no-preference)` 整段即可全部关闭。

## 几处刻意的设计

1. **不设详情页**：整张卡片就是一个外链，点哪儿都直达官方入口，少一次点击。
2. **截止日自动算天数**：`dl` 在 7 天内显示“剩 N 天”并变琥珀色，当天变珊瑚色，过期划掉。
3. **筛选是纯前端**：搜索框支持 `/` 聚焦、`Esc` 清空；分类与“只看有截止日”可叠加。
4. **收录结果与广告分离**：卡片链接全是平台官方地址，没有 `?aff=`、`?invite=` 之类返佣参数；广告只出现在左右侧栏，且明确标注。

## 维护提醒

- 额度政策变化很快，建议每周过一遍 `items`，失效的移到 `retired`，存疑的移到 `watch`。
- 新增条目时优先用平台官方首页/控制台地址，别用短链和推广链，短链会失效。
- 链接失效排查：浏览器打开对应卡片，若 404 或跳到首页，就把该条移入 `retired`。
